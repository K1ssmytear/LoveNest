# LoveNest
- 懒蛋蛋的好用分享。

## 目前有什么

- [觉得很赞的那些提示词们](favorite-prompts/)：我交心的、信任的、心连心的提示词，攒攒，给了给了。
- [聊天界面三模式切换](chat-modes/)：聊天界面内三模式切换（日常/长聊/场景）的设计，可手动+机自动切换。整理了框架和思路，可按需改。
- [小机视角的聊天截图](pov-snap/)：让机自己挑一段聊天，从它的视角截图（它的话在右边），截出来跟你当前的主题和美化一模一样。附给机看的实施步骤，网页和 iOS 的示范写法。
- [喵喵铃](meow-bell/)：朋友有急事找不到你，用专属链接留言，先交给你家 AI 判断急不急，真急才叫醒你（静音也会响，或者打电话，自己选）。附思路、判断标准、防乱用的规矩，和一个像素老 Mac 风的界面模板。
